# Certificates

Place real certificate files here (PDF, PNG, JPG, JPEG or WebP), for example:

    python-infosys.pdf
    dbms-nptel.pdf
    javascript-simplilearn.pdf
    html-udemy.pdf
    national-agritech-hackathon.pdf
    x-horizon.pdf
    servicenow-micro-certification.pdf

Then set the matching `fileUrl` in `CERTIFICATES` inside
`src/lib/portfolio-data.ts`, e.g. `fileUrl: "/certificates/python-infosys.pdf"`.

Cards with no file show "Certificate pending upload" instead of a broken link.
