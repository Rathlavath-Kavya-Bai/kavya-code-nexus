# Resume

Place the real resume PDF here as:

    Kavya_Bai_Rathlavath_Resume.pdf

Then open `src/lib/portfolio-data.ts` and set:

    export const RESUME_URL = "/resume/Kavya_Bai_Rathlavath_Resume.pdf";

Until that is done, the site never links to a missing file — the Resume
buttons appear only after a file is configured or uploaded via owner edit mode.
